# BUILD-016 Phase 2 — NSE selector map

| Configuration key | Selector / interaction | Why it is stable |
| --- | --- | --- |
| `calendarEquitiesHeading` | Visible text `Holidays for the calendar year` | This is NSE's public calendar section heading, rather than a generated CSS class or a table position. |
| `fiiDiiNseHeading` | Exact visible report title `FII/FPI & DII trading activity on NSE in Capital Market Segment` | It identifies the NSE-only report by its user-facing business label. It avoids the adjacent combined NSE/BSE/MSEI report and any filename heuristic. |
| `downloadLinkText` | The first `Download (.csv)` link following the NSE-only heading | The traversal is anchored to the report title and to NSE's explicit download call-to-action, not an ordinal page-wide button or unstable DOM classes. |

URLs, navigation timeouts, artifact locations, retry defaults, and every selector above are defined only in `lib/nse-reports/config.ts`.

If NSE changes a public label, update that configuration and this map together. Do not add generated CSS selectors, autogenerated IDs, or filename checks as fallbacks: those make the downloader silently choose the wrong report.
